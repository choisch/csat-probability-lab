# 수능 확률 연구소 · 공개 베타

2026-11-27 기준. 기출 정답 통계 및 가상 답안 전략 실험용 독립 프로젝트입니다. 정적 사이트로 회원가입, API, 서버 데이터베이스 없이 실행됩니다.

## 실행 및 배포

- `index.html`을 일반 브라우저에서 열거나 정적 웹호스팅에 업로드합니다. 모든 데이터와 스크립트가 포함되어 있습니다.
- GitHub Pages에서는 Settings → Pages에서 Deploy from a branch, `main`, `/ (root)`를 선택합니다. 이 프로젝트는 저장소 이름을 포함한 하위 경로에서도 동작합니다.
- 재빌드: Python 3 및 numpy 설치 후 `python build_data.py`, `python analyze.py`, `python build_site.py` 순서로 실행합니다.
- 브라우저 테스트: Playwright와 Chromium을 설치한 뒤 `python test_site.py`. 테스트 환경의 경로는 필요시 변경합니다.

## 수집 범위

- 2022~2026학년도 수능 본시험 11개 과목·선택 경로, 2018~2021학년도 영어 본시험, 2027학년도 잠정 정답(국어·수학·영어), 영어 일부 6/9월 모의평가.
- 1,619개 고유 객관식 문항(과거 본시험 1,350, 과거 모의평가 135, 잠정 본시험 134), 68개 시험지·선택 경로. 추가로 영어 3개년 홀수형·짝수형 비교를 분리 수록(135개 번호 쌍, 본문 통계 중복 합산하지 않음).
- 국어 공통 및 수학 공통은 전체 통계에서 고유 ID로 중복 제거. 수학 단답형 제외.

## 파일 구조

- `data/answers.csv`: 고유 문항. id, academic_year, exam, block, question, answer, status, form, source, points.
- `data/papers.json`: 응시 경로 및 객관식 문항 참조 ID 목록.
- `data/dataset.json`: 사이트용 통합 데이터.
- `data/english_seed.csv`: 기존 영어 수능 데이터.
- `data/form_comparison.json`: 영어 홀수형·짝수형 비교 및 출처.
- `data/analysis.json`: 순차 검증 결과 및 독립 균등 모형 비교값.
- `build_data.py`: 공개 자료에서 전사한 정답 번호와 검증 규칙.
- `analyze.py`: 시드 고정 가상 답안 실험. 영어 2020~2026학년도, 나머지 과목 2024~2026학년도 각 시험의 이전 학년도만 학습. 시험당 조건별 5,000회. 모든 틀린 응답은 다른 4개 선지에 균등하다고 가정. 동률 균등 처리. 무작위 기준은 이론값 20%. 과거 평균 부족분은 오답을 대칭 오차로 보정한 번호별 차이 휴리스틱이며 사후확률이 아님.
- `template.html`, `build_site.py`, `index.html`: 화면 및 정적 번들.
- `test_site.py`: 브라우저 기능 테스트.

## 출처와 한계

문항 번호, 정답 번호, 일부 배점과 출처 링크를 제공합니다. 2026·2027학년도 국어와 2027학년도 수학은 EBSi에 게시된 홀수형 정답표와 대조했습니다. 각 데이터의 출처는 `data/answers.csv`와 화면의 데이터 메뉴에서 확인할 수 있습니다. 그 밖의 자료는 평가원 원본과 전수 대조하지 않았으며, 시험지 형태를 확인하지 못한 경우 대표형으로 표기했습니다.

2027학년도 본시험 답안은 잠정 자료로 표시하고 전략 실험과 채점 연습에서 제외했습니다. [평가원 공지](https://cdn2.kice.re.kr/imsi/27dae-suneung/popup.html)에 따른 정답 확정 발표 예정은 2026년 12월 1일 오후 5시입니다.

실험은 가상 응답에 대한 과거 데이터 검증입니다. 실제 시험 점수 개선을 입증하지 않습니다. 영어는 7개년, 그 외 과목은 3개년을 검증했으며, 국어·수학 선택과목은 공통 문항을 공유합니다.
